# 06 账号权限与数据模型

## 本文档解决什么问题

v1 PRD 的家长端要看孩子的诊断结果，教师端要看全班统计，4.4.4 的「同一学生多次同类错误」要看历史，批量批改要处理多人数据，迭代规划还承诺千人级并发。这些功能全部隐含依赖一套账号与数据体系，而 v1 全文没有出现登录、用户、班级、权限任何一个字。

后果有两个：技术侧无模型可依；合规侧有实质风险——涉及未成年人的个人信息，「符合《个人信息保护法》」这六个字本身不构成任何措施。

本文档定义角色、实体、数据可见性矩阵，并把 v1 §6.4 的口号式表述改为可验收条款。

## 前置依赖与文档关系

掌握度报告的数据可见性由本文档 §3 约束（[05-mastery-model.md](./05-mastery-model.md) §6 的报告字段只对可见对象开放）；结构化回流与训练用途开关见 §5；家长绑定与教师授权的撤销路径见 §6。

---

## 1. 角色定义

| 角色 | 主体 | 核心诉求 | 权限范围 |
|---|---|---|---|
| 学生 | 小学生本人 | 弄懂自己错在哪 | 仅本人数据 |
| 家长 | 监护人 | 辅导孩子 | 绑定子女的数据 |
| 教师 | 小学数学教师 | 批改与讲评 | 授权班级内学生的数据 |
| 管理员 | 教研与运营 | 维护规则库、审核错误模式 | 规则与审核数据，**不含**学生个人数据 |

**管理员不默认拥有学生个人数据访问权**。规则维护需要的是错误模式与匿名化后的失败案例，不是可识别到具体学生的记录。需要排查个案时，走 §6.3 的一次性授权流程。

## 2. 实体与数据模型

| 实体 | 关键字段 | 关联关系 | 敏感级别 |
|---|---|---|---|
| 用户 | id、角色、状态 | 与角色表一对多 | 中 |
| 学生档案 | id、年级、教材版本、绑定码 | 多对一用户 | 高 |
| 家长学生绑定 | 家长 id、学生 id、关系、状态 | 多对多 | 高 |
| 班级 | id、名称、年级 | 多对多学生 | 中 |
| 教师班级授权 | 教师 id、班级 id、授权人 id、有效期 | 多对多 | 高 |
| 作业 | id、班级 id、来源、提交时间 | 多对多学生 | 中 |
| 作业照片 | id、存储引用、上传者、页数 | 多对一作业 | 高 |
| 诊断记录 | id、学生 id、题目标识、判定结论、错误分类、知识点、代价明细 | 多对一学生 | 高 |
| 诊断快照 | id、schema 版本、规则库版本、模型版本、模板版本、完整 IR | 多对一诊断记录 | 高 |
| 错题本条目 | id、学生 id、知识点、状态 | 多对一学生 | 中 |
| 掌握度快照 | 学生 id、知识点、分数、等级、统计周期 | 多对多知识点 | 高 |
| 错误模式审核条目 | id、模式描述、关联规则、审核状态、提交人 | 独立 | 低 |
| 规则版本 | 版本号、变更说明、生效时间 | 独立 | 低 |

**存储原则**：作业照片与诊断快照分开存储，删除其中一类不影响另一类。诊断快照是争议复核与结果复现的唯一依据，保留期长于诊断记录本身。

## 3. 数据可见性矩阵

取值：✓ 可读 / ✎ 可写 / ○ 不可见。

| 数据对象 | 学生本人 | 家长（绑定子女） | 教师（授权班级） | 管理员 |
|---|---|---|---|---|
| 作业照片 | ✓ 本人 | ✓ 子女 | ✓ 班级 | ○ |
| 诊断结论 | ✓ 本人 | ✓ 子女 | ✓ 班级 | ○ |
| 诊断快照 | ✓ 本人 | ✕ | ✕ | ○ |
| 错题本 | ✓ 本人 | ✓ 子女（只读） | ✕ | ○ |
| 掌握度报告 | ✓ 本人 | ✓ 子女 | ✓ 班级（聚合） | ○ |
| 班级统计 | ✕ | ✕ | ✓ 本班 | ○ |
| 错误模式审核池 | ✕ | ✕ | ✓ 只读 | ✓ |
| 规则库 | 只读 | 只读 | 只读 | ✓ |
| 评测集 | ✕ | ✕ | ✕ | ✓ |

两条容易漏掉的边界：

1. **诊断快照不向家长与教师开放**。快照含完整 IR 与内部判定代价，属实现数据，可能包含尚未对外展示的中间结论。对外只暴露结论层。
2. **错题本对家长只读**。家长可以看，但不能替孩子增删——错题本是学生的订正清单，代劳会削弱订正价值。

可见性按**行列逐格判定**，不做「角色整体授权」。

**导出与查看的区分**：导出打印是只读的延伸，不修改数据，因此家长可导出错题本（只读角色 + 导出权），教师不可导出（本就无查看权）。导出规格与版式见 [11-interaction-flows.md](./11-interaction-flows.md) §8，该处为权威口径。

## 4. 账号与绑定流程

| 流程 | 步骤 | 关键约束 |
|---|---|---|
| 学生注册 | 家长创建学生档案 → 生成一次性绑定码 → 学生输入绑定码 | 绑定码 24 小时有效，单次使用 |
| 家长绑定 | 输入绑定码或扫码 → 验证监护关系 → 建立绑定 | 需验证监护关系，不能只凭绑定码 |
| 教师加入班级 | 管理员或班主任创建班级 → 邀请教师 → 教师确认 → 授权生效 | 授权有有效期，默认一学期 |
| 学生毕业 | 班级归档 → 授权自动失效 → 数据按留存规则处理 | 不删除历史数据，但解绑关系 |

**监护关系验证**是 v1 完全缺失的一环。未成年人数据由监护人同意才可收集，仅靠绑定码不足以确立合法性。

## 5. 未成年人数据与合规条款

**商业模式相关实体待定价后补充**：订阅、订单、付费状态、班级规模上限等实体不在本版数据模型中（见 [10-assumptions-and-limits.md](./10-assumptions-and-limits.md) §3）。当前模型已预留承载点：教师班级授权带有效期、班级人数未设硬编码，可承接后续采购或订阅档位。

v1 §6.4 只有「符合《个人信息保护法》」「不收集敏感信息」「所有 AI 生成内容符合教育导向」三句口号，其中第三句不可测、无法验收。替换为下列可验收条款。

| 编号 | 条款 | 验收方式 | 对应 v1 表述 |
|---|---|---|---|
| C-1 | 收集未成年人个人信息须取得监护人同意，留存同意记录（同意时间、渠道、版本号） | 抽查账号无同意记录 | 「符合《个人信息保护法》」 |
| C-2 | **训练用途默认关闭**，且为可配置项 | 检查配置缺省值为关闭 | 无（v1 未涉及） |
| C-3 | 监护人可撤回同意，撤回后 30 日内删除已进入训练集的数据并停止后续使用 | 走通一次撤回流程 | 无 |
| C-4 | 不收集身份证号、人脸、声纹、精确位置；家长绑定仅用一次性绑定码 | 抽查数据表字段 | 「不收集敏感信息」 |
| C-5 | 作业照片留存 ≤24 个月，诊断记录 ≤36 个月，到期自动删除且不可恢复 | 检查清理任务 | 无 |
| C-6 | 监护人可请求删除指定数据，15 工作日内完成；法定留存义务的数据除外 | 走通一次删除请求 | 无 |
| C-7 | 传给大模型服务的内容仅限表达式与步骤文本，**不含**姓名、学校、班级、照片 | 检查外发内容白名单 | 无 |
| C-8 | 外发前告知用途与服务提供方，敏感字段脱敏 | 检查告知文案与脱敏规则 | 无 |
| C-9 | 学生可查看自己的数据，可更正与删除 | 走通一次查询更正 | 无 |
| C-10 | 模型生成内容不进入学生正式作业记录，只作参考 | 检查写入路径 | 「所有 AI 生成内容符合教育导向」 |
| C-11 | 生成内容设置禁用清单（暴力、歧视、不当言论、超纲不当引导），命中即拦截 | 走通一次拦截用例 | 同上 |

C-10 与 C-11 是 v1 那句口号的可执行版本。「符合教育导向」不是一个可验收的条件，「写入路径受控 + 禁用清单命中拦截」才是。

## 6. 授权的授予与撤销

### 6.1 家长与学生

| 场景 | 处理 |
|---|---|
| 绑定建立 | 验证监护关系后生效 |
| 监护关系变更（离异、重组） | 保留原绑定记录，标注关系变更，不自动解除 |
| 主动解除 | 立即解除，子女数据不再可见 |
| 学生成年 | 自动解除家长可见权限，数据由学生本人接管 |

**解除后数据不删除**，只解除可见性。删除权由 §5 C-6 单独行使。

### 6.2 教师与班级

| 场景 | 处理 |
|---|---|
| 授权建立 | 班主任或管理员发起，有有效期 |
| 学期结束 | 自动失效，不自动续期 |
| 离校 | 立即失效，剩余授权记录保留备查 |
| 手动撤销 | 立即生效，撤销后该教师无法访问此前已缓存的数据（缓存需同步失效） |

### 6.3 临时授权（管理员访问个案）

1. 提出申请，填写事由与所需数据范围。
2. 班主任或家长同意（涉及学生个人数据时）。
3. 授权有效期 ≤7 天，范围限定到指定诊断记录。
4. 到期自动失效，操作全程留痕（审计日志字段、留存期与不可篡改要求见 [13-resilience-and-maintainability.md](./13-resilience-and-maintainability.md) §5）。

## 7. 保留、删除与导出

| 数据 | 保留期 | 到期处理 | 用户可主动删除 |
|---|---|---|---|
| 作业照片 | 24 个月 | 删除 | 是 |
| 诊断记录 | 36 个月 | 删除，保留聚合统计 | 是 |
| 诊断快照 | 12 个月 | 删除 | 是 |
| 掌握度快照 | 36 个月 | 删除 | 是 |
| 班级统计 | 24 个月 | 删除 | 教师可申请 |
| 审核池条目 | 长期 | 不删除 | 管理员可清理 |
| 规则库与评测集 | 长期 | 不删除 | 不适用 |

**评测集的例外**：真实采集的学生错误样本在进入评测集时必须去标识化（去姓名、学校、班级，题目文本保留），去标识化后的样本不受 C-5 保留期约束，但须记录脱敏处理。

## 8. 验收清单

- [ ] 角色、实体、关联关系、敏感级别四项齐全
- [ ] 数据可见性矩阵逐格判定，两条特殊边界（快照、错题本只读）成文
- [ ] 四条账号流程均有监护关系验证与有效期约束
- [ ] 十一条合规条款均有验收方式
- [ ] 训练用途默认关闭且可配置
- [ ] 外发大模型的内容白名单明确排除姓名、学校、班级、照片
- [ ] 授权撤销路径完整，撤销后缓存同步失效
- [ ] 保留期、到期处理、用户删除权三项成表
- [ ] 评测集去标识化规则成文
