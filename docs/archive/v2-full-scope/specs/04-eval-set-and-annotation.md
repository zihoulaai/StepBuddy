# 04 评测集与标注规范

## 本文档解决什么问题

v1 PRD 有四个数字：步骤级判定准确率 ≥95%、错误原因归因准确率 ≥90%、模型结构化转换准确率 ≥98%、题型覆盖率 ≥90%。四个数字都没有定义式、没有分母、没有评测集，汇报时回答不了「在多少题上测的、谁标的、怎么算的」。

本文档把这四个数字变成可计算的口径，并补两个 v1 完全没有的指标：确定性一致率，支撑「同一道题多次诊断结果一致」；学习效果指标，支撑「精准学习」这个愿景。

当前项目无教研资源，全部准确率指标标注 `AI 自评·内部口径`，对外宣传门槛见 §5。

## 前置依赖与文档关系

## 2. 指标定义

### 2.1 三个准确率

**M-1 步骤级判定准确率**

$$M_1 = \frac{\text{系统与标注判定一致的步数}}{\text{可判定步总数}}$$

| 项 | 内容 |
|---|---|
| 判定单元 | 一个学生步骤 |
| 一致的定义 | 双方均判对，或双方均判错且错误步骤位置相同 |
| 可判定步 | 排除「无法判定」标记的步骤 |
| 排除项 | 见 §2.3 |

**M-2 错误原因归因准确率**

$$M_2 = \frac{\text{归因与标注一致的错误步数}}{\text{系统判错的错误步总数}}$$

| 项 | 内容 |
|---|---|
| 判定单元 | 一个被判错的步骤 |
| 一致的定义 | 错误分类（知识性 / 行为性 / 规范性）一致**且**规则级定位指向同一元规则；两者任一不一致即记为不一致 |
| 子项 | 笔误判定准确率单独统计，不混入本指标分母 |

只测分类不测规则定位是不够的。分类对了但指向错误的规则（比如把通分错误说成约分错误），家长看到后仍然无法辅导。

**M-3 结构化准确率**

v1 用一个数字概括结构化质量，实际三项难度差异极大，混在一起无法定位问题。

| 子项 | 定义式 | 说明 |
|---|---|---|
| M-3a 表达式解析准确率 | 解析结果与人工标注表达式一致的步数 / 总步数 | 最易达成，v1 的 98% 大致对应此项 |
| M-3b 关系角色准确率 | 四个角色（主体 / 基准量 / 比较量 / 运算关系）全部正确的题数 / 含关系层的题数 | 四个全对才算对，是结构化的真实难点 |
| M-3c 原子步切分准确率 | 切分边界与人工标注一致的步数 / 总步数 | 对应 [01-ir-schema.md](./01-ir-schema.md) §6.1 的 INV-1，v1 完全没有考虑这一项 |

M-3c 是诊断准确率的前置条件。切分错了，表达式解析再准，M-1 也不可能达标。

### 2.2 M-5 确定性一致率

支撑核心目标「同一道题多次诊断结果一致」。

| 项 | 内容 |
|---|---|
| 测量方式 | 从评测集抽 100 题，重复诊断 5 次 |
| 规则层一致率 | 5 次核心判定（对错结论 + 错误步骤位置）完全相同的题数 / 100，要求 100% |
| IR 层一致率 | 5 次 IR 规范化后表达式完全相同的题数 / 100，要求 ≥99% |

规则层必须 100%：规则引擎是确定性的，达不到即为缺陷而非指标波动。IR 层允许 <100%，波动来自结构化环节的大模型调用，缓解手段见 §8.2。

### 2.3 排除项

以下情况不计入任何准确率分母，且必须在报告中单独披露数量：

| 排除项 | 原因 |
|---|---|
| 只写答案不写过程 | 没有推理过程可判定（见 03 §8.3） |
| 表达式无效 | 算式本身写错，不构成诊断对象（见 03 §8.4） |
| 图形未解析 | 图形相关步骤未校验（见 03 §8.5） |
| 题型在覆盖矩阵外 | 无规则可依 |
| 结构化重试 3 次仍失败 | 未产出 IR |

排除项占比是健康度指标。占比过高说明输入环节或覆盖范围有问题，必须单列分析而不是 quietly 排除。

### 2.4 终局目标与阶段承诺

v1 把终局数字直接当阶段交付标准，这是不可验收的根源。两套数字分列如下。

| 口径 | 覆盖范围 | M-1 | M-2 | M-3a | M-3b | M-3c |
|---|---|---|---|---|---|---|
| 终局目标 | 1-6 年级全部题型族（分母见 02 §3.5） | ≥95% | ≥90% | ≥98% | ≥95% | ≥90% |
| P0 阶段承诺 | 八类：整数四则、小数四则、列式计算（一步与两步）、解方程、简便运算、分数四则、应用题·和差倍、应用题·归一归总 | ≥90% | ≥85% | ≥95% | ≥92% | ≥85% |
| P1 阶段承诺 | P0 范围 + 应用题·平均数、应用题·等差与年龄、应用题·鸡兔同笼与盈亏、几何计算（以图形解析就绪为前置） | ≥93% | ≥88% | ≥97% | ≥93% | ≥88% |

三条约束：

1. 阶段承诺的题型范围必须与 [02-coverage-matrix.md](./02-coverage-matrix.md) 的阶段承诺列一致，就绪状态未达标的题型族不计入阶段承诺分母。
2. 分母变化（02 §3.5 规则 2）发生时，覆盖率数字必须同步公布。
3. **禁止**在阶段验收时引用终局目标的数字。

P0 覆盖八类题型族后，阈值未下调。代价有三个，都写在明处：P0 规则交付量升至 49 – 76 条（02 §4）、`REL.MODEL` 两族从零开始编写、P0 工期为 3 个月。工期与规则量的对应关系见 PRD §7.1。

**达成时间线**（各指标何时达到哪一档）：

| 指标 | P0 结束 | P1 结束 | 终局 |
|---|---|---|---|
| M-1 步骤级判定准确率 | ≥90% | ≥93% | ≥95% |
| M-2 归因准确率 | ≥85% | ≥88% | ≥90% |
| M-3a/b/c 结构化三项 | ≥95%/≥92%/≥85% | ≥97%/≥93%/≥88% | ≥98%/≥95%/≥90% |
| M-4 题型覆盖率 | 分母含 P0 八类 | 分母扩展至 P1 范围 | 分母含全部题型族 |
| M-5 确定性一致率 | 规则层 100%、IR 层 ≥99% | 同 | 同 |
| M-6 学习效果 | 不可测 | 不可测 | P2 起可测，目标 ≥10 个百分点 |

终局目标的达成时点**未在本文档设定**，需在教研复核完成、范围与产能确定后回填。当前只承诺阶段阈值。

### 2.5 M-4 题型覆盖率

覆盖率的分母、完备度判据与三条防虚高规则定义在 [02-coverage-matrix.md](./02-coverage-matrix.md) §3.5，本文档不重复。评测集必须覆盖分母中标记为「完备」的全部行，否则覆盖率无法验证。

### 2.6 指标三件套检查

每个指标对外呈现时必须同时给出：数值、口径标签、定义引用。缺任一项视为未完成。当前允许出现的标签只有 `AI 自评·内部口径`，因此所有准确率数字**一律不得进入对外材料**。

## 3. 评测集构成

### 3.1 分层配比

| 维度 | 分层 | P0 配比 | P1 配比 |
|---|---|---|---|
| 年级 | G1–G6 | 各 15% – 18% | 各 15% – 18% |
| 难度 | 简单 / 中等 / 困难 | 40% / 45% / 15% | 35% / 45% / 20% |
| 错误类型 | 无错 / 知识性 / 行为性 / 规范性 / 笔误 | 30% / 25% / 25% / 12% / 8% | 25% / 27% / 25% / 13% / 10% |
| 书写形态 | 印刷体 / 手写体 | 40% / 60% | 35% / 65% |
| 题型族 | 见下表 | 八族均分，见下 | P0 八族合计 70%，其余四族见下 |

P0 覆盖 13 个矩阵行（八类题型族），按题型族分配配比：

| 题型族 | P0 配比 | 理由 |
|---|---|---|
| 整数四则 | 12% | 基础，题量充足 |
| 小数四则 | 12% | 与整数四则同构 |
| 列式计算（一步与两步） | 12% | 含新增的两步运算 |
| 解方程 | 12% | 形式等价判定的试金石 |
| 简便运算 | 14% | 作业中出现频率最高的计算类题型之一 |
| 分数四则 | 16% | 规则量最大（12 – 18 条），需要足够样本覆盖各条规则 |
| 应用题·和差倍 | 11% | 关系层建模，关系角色准确率的主要样本来源 |
| 应用题·归一归总 | 11% | 同上 |

**应用题两族在 P0 合计不低于 22%**。这条下限是硬约束：`REL.MODEL` 两族是本轮新增缺口，M-3b 关系角色准确率（阈值 ≥92%）只能靠这类样本验收。样本不足时该指标不可测，退化结果是被迫下调阈值或跳过验收，两者都不可接受。

P1 配比：上表八族合计 70%，应用题·平均数 6%、应用题·等差与年龄 6%、应用题·鸡兔同笼与盈亏 6%、几何计算 12%。

手写体占比不低于 50% 是刻意约束：真实作业以手写为主。全部用印刷体验证过的系统不能代表实际使用状态，v1 的非功能需求里完全没有这一条。

### 3.2 样本量

| 用途 | 题量 | 说明 |
|---|---|---|
| 主评测集 | 2000 | P1 完整范围，按上表配比 |
| P0 子集 | 1200 | 从主评测集中筛出 P0 承诺题型 |
| 一致性子集 | 100 | 供 M-5 重复诊断使用 |
| 单条规则验收 | 每条规则 ≥ 3 | 编号 `EV-<题型族>-<序号>`，来自 02 §4 |

**P0 子集从 600 提到 1200 的原因**：P0 覆盖族数从 4 增到 8，600 题摊到八族后每族不足百题。分数四则一族就有 12 – 18 条规则，每条规则至少 3 个验收用例需要 36 – 54 题才够用；应用题两族各 11% 意味着约 130 题，扣掉排除项后不足以验收 M-3b。

**置信区间论证**：

| 项 | 数值 |
|---|---|
| P0 子集题量 | 1200 |
| 平均每题可判定步 | 约 4 步 |
| 可判定步总数 | 约 4800 步 |
| 在 p = 0.9 时的标准误 | `sqrt(0.9 × 0.1 / 4800)` ≈ 0.0043 |
| 95% 置信区间半宽 | 约 0.85 个百分点 |

半宽 0.85 个百分点小于 M-1 阈值 90% 与 92% 之间的 2 个百分点差距，足以区分两档。这一约束必须写进验收标准：样本量不达标时，准确率的小幅提升无法与噪声区分，91% 与 92% 会被误读为「有提升」。

**主集与子集的从属关系**：主评测集 2000 题中 P0 题型占 70%（约 1400 题），因此筛出 1200 题的 P0 子集无需额外采集。P1 阶段若扩展题型范围，主集需按新配比重新采集，不能沿用。

### 3.3 来源与合规

| 来源类型 | 许可要求 | 边界 |
|---|---|---|
| 公开教育资源平台题目 | 记录平台名称与题目标识 | 保留来源记录 |
| 教材例题与习题 | 仅收录题目本身 | **不收录教材完整页面**，不复制受版权保护的正文与插图 |
| 公开试题与真题 | 记录年份与来源 | 商业教辅内容一律不入库 |
| 自编题 | 内部使用 | 需通过 §4 标注校验 |

去重规则：题目文本归一化后完全相同视为重复，保留来源等级最高的一份；同一知识点同一难度下重复题不超过 2 道。

### 3.4 错误样本的构造

评测集必须包含**非正确解法**，这是 v1 完全没提却极其关键的部分。

| 构造方式 | 占比 | 举例 |
|---|---|---|
| 真实采集 | 40% | 学生实际错误步骤，须脱敏后使用 |
| 人工构造 | 30% | 依 02 §4 的错误模式清单构造典型错例 |
| 模型构造 | 30% | 由结构化环节生成错误解法候选，人工筛选确认 |

**禁止**只用正确解法评测。只测对错准确率会掩盖一个致命问题：系统在「学生写对时」表现好，在「学生写错时」给出错误归因，而后者才是产品核心价值。评测集若只有正确答案，M-2 归因准确率将永远无法被测量。

## 4. 标注规范

### 4.1 标注单元

| 标注类型 | 单元 | 产出字段 |
|---|---|---|
| 表达式标注 | 一个步骤 | `expr_after` 规范形 |
| 关系标注 | 一条关系 | 四个角色 + 谓词 |
| 切分标注 | 一个步骤 | 原子步边界 |
| 判定标注 | 一个步骤 | 对错 + 错误分类 + 规则标识 |
| 难度标注 | 一道题 | 简单 / 中等 / 困难 |

### 4.2 标注者与口径

| 阶段 | 标注者 | 一致性要求 | 报告标签 |
|---|---|---|---|
| 当前 | AI 自评 | 无法计算一致性 | `AI 自评·内部口径，待教研复核` |
| 教研到位后 | 双人独立标注 | Cohen's Kappa ≥ 0.8，低于则重标 | `教研复核·可对外` |

**当前状态必须显式出现在报告中**：单标注者、无一致性系数、无法排除标注漂移。这不是免责声明，是让读报告的人知道这个数字的证据强度。

### 4.3 双标流程（预留）

教研专家到位后启用：两人独立标注同一批样本 → 计算 Kappa → 低于 0.8 则逐条讨论重标 → 达标后合并为金标集。争议条目进入难例集，用于补充错误模式库。

### 4.4 争议裁决

当前阶段无第二标注者。标注方给出理由说明并标记为「存疑」，存疑样本单独统计。存疑比例超过 8% 时说明标注规范本身有歧义，须先修订规范再继续标注。

### 4.5 标注模板

每条样本记录：题号、题型族标识、年级、难度、步骤序列、各步骤表达式规范形、切分边界、逐步对错与错误分类、规则标识、标注理由、标注者、标注时间、是否存疑。

示例（对应 [01-ir-schema.md](./01-ir-schema.md) §8.1）：

| 项 | 内容 |
|---|---|
| 题号 | EV-FRAC-007 |
| 步骤 1 | `1/2 * 2/3` → `2/3`，判错，行为性错误，`NUM.FRAC.MUL`，理由：只乘了其中一个因数 |
| 步骤 2 | `3/4 + 2/3` → `9/12 + 8/12` → `17/12`，判对（继承错误，不计负面证据） |

### 4.6 人工审核池质量指标

PRD 4.5.3 定义了审核池的 SLA（5 个工作日），但审核池自己也需要被度量，否则会成为准确率黑箱。

| 指标 | 定义 | 目标 |
|---|---|---|
| 审核通过率 | 通过条数 / 处理条数 | **待定**，首个季度实测后回填基线 |
| 平均处理时长 | 从进入审核池到完成处理 | ≤5 个工作日（PRD 4.5.3） |
| 沉淀转化率 | 转化为正式规则或错误模式的条数 / 通过条数 | **待定** |
| 驳回原因分布 | 按原因分类的占比 | 用于发现规则库的共性问题 |

审核通过率与沉淀转化率的目标值留空是刻意的：当前无教研资源，实测数据出现前设定目标等于臆测。首个季度实测后回填，并作为后续季度的基线。

## 5. 对外承诺门槛

| 条件 | 内容 |
|---|---|
| 门槛 | 全部对外准确率数字须经教研专家复核并签署，标签升级为 `教研复核·可对外` |
| 当前状态 | **未签署**。本文档全部数字禁止进入对外宣传材料、产品介绍、招生材料 |
| 复核工作量 | 主评测集抽 200 题双人标注即可满足签署条件，无需全量 |
| 复核完成后 | 重跑全量评测，替换本文件中的初始值并更新 00 的术语表标签说明 |

不得用「AI 自评」结果对外承诺任何数字，也不得在宣传中省略口径标签。

**复核后指标下降的预期**：AI 自评天然偏乐观，教研复核后准确率必然下降。本版预设下降区间为 **2 至 8 个百分点**（待首次复核后校准）。

| 复核结果 | 处理 |
|---|---|
| 下降 ≤2 个百分点 | 自评可信，直接采用复核值 |
| 下降 2 – 8 个百分点 | 预期内，采用复核值并校准自评模型 |
| 下降 >8 个百分点 | 自评机制失效，须重建标注流程后再对外承诺 |
| 低于所在阶段阈值 | 按 PRD §8.4 原则处理：优先收窄承诺范围，而非放宽指标 |

下降区间未校准前，任何「复核后仍达标」的推断都不成立。

## 6. M-6 学习效果提升（北极星指标）

v1 的四个目标全是系统指标，没有一个能证明「精准学习」实现了。

**定义**：学生首次诊断出某知识点错误后，7 日内在同类题上的正确率，减去首次诊断前 30 日内同类题正确率均值。

$$M_6 = \text{正确率(首次诊断后 7 日同类题)} - \text{正确率(首次诊断前 30 日同类题均值)}$$

| 项 | 内容 |
|---|---|
| 判定单元 | 一个学生 |
| 测量窗口 | 7 日，逾期样本不计入 |
| 对照方式 | 同一学生自身前后对比，不做跨学生比较 |
| 达成阈值 | P2 首个可测量周期内提升 **≥10 个百分点**（待教研复核后确认） |
| 依赖埋点 | 诊断事件、知识点标注、练习作答事件、练习题目知识点映射 |

**当前状态：不可测**。同类题练习功能已后置到 P2（见 00 §4.4 的 D-2），因此 M-6 在练习功能上线前无法采集数据。P0 与 P1 阶段该指标记为「数据不足」，**不得**用任何替代指标冒充学习效果。

**为什么取 10 个百分点**：测量窗口只有 7 天、样本量有限，更小的提升无法与噪声区分。若后续样本量足以支撑更小阈值的检验，可下调至 5 个百分点。

**测不出的后果**：若 P2 首个周期内该指标不可测（家长不打开报告、学生不使用同类题练习），说明 PRD 1.3 的「精准学习」愿景未获得证据支持。此时应回到 [10-assumptions-and-limits.md](./10-assumptions-and-limits.md) §1 的 H-3、H-4 假设重新验证，而不是继续扩大功能范围。

## 7. M-7 讲解可读性与家长可理解度

v1 的核心目标写「学生能看懂、家长能辅导、老师能参考」，但没有任何测量方式。

| 子项 | 测量方式 | 目标值 |
|---|---|---|
| 阅读年级水平 | 讲解文本的句子平均字数、生僻字密度、句式复杂度 | 不超过对应年级 + 1 年水平 |
| 家长可理解度 | 每题抽取 30 份，家长阅读后回答「能否说出孩子错在哪一步」 | 抽样通过率 ≥85% |
| 讲解归因可追溯率 | 讲解中每个错误原因能追溯到 `transforms` 条目的比例 | 100% |

**归因可追溯率是硬约束**，不是体验指标。追溯不到的解释不能出现在「错误原因」区，只能出现在「教学建议」区（见 [01-ir-schema.md](./01-ir-schema.md) §5）。这条约束同时防止大模型编造理由。

## 8. 评测执行与回归

### 8.1 执行时机

| 时机 | 范围 | 用途 |
|---|---|---|
| 规则库变更 | 主评测集全量 | 发布前回归 |
| 错误模式库变更 | 主评测集全量 | 发布前回归 |
| 诊断算法变更 | 主评测集全量 + 一致性子集 | 发布前回归 |
| 结构化提示词变更 | 主评测集全量 + 排除项统计 | 观察结构化准确率与退化率 |
| 日常 | 每日抽样 100 题 | 趋势监控 |

### 8.2 确定性保障措施

IR 层一致率低于 99% 时，按以下顺序处理：固定解码参数使输出近于确定 → 锁定模型版本 → 提示词模板版本化并冻结 → 对已诊断题目复用结构化结果（缓存） → 仍不达标则该题进入人工确认。

**不得**用「多次调用取多数结果」来掩盖不确定性：这既不解决根因，又会让响应时间翻倍。

### 8.3 阻断规则

| 条件 | 处置 |
|---|---|
| 任一准确率指标低于所在阶段承诺值 | 阻断发布 |
| 规则层一致率 < 100% | 阻断发布 |
| 排除项占比较基线上升超过 5 个百分点 | 阻断发布，先查输入环节 |
| 新增规则未附验收用例 | 阻断发布 |
| 错误样本占比低于 20% | 阻断发布，评测集结构失衡 |
